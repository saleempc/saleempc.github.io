# AI Use Cases, Built & Live

Standalone portfolio page listing live AI applications, for sharing and CVs.
Live at **https://saleempc.github.io/**

## Edit the app list
Open `index.html`, find the `EDIT HERE` block and edit the `APPS` list (name, url, tagline, img, status).
- `status`: `live` (open to all), `signin` (live, sign-in needed) or `private` (owner-only)
- `BYLINE`: optional name / role line above the headline
- Preview images live in `img/` (800×500 JPG works best)

Commit the change (or edit directly on github.com) and GitHub Pages republishes in about a minute.
